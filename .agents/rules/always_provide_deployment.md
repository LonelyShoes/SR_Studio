# Deployment Files Delivery Rule

Setiap kali menyelesaikan perbaikan bug, penambahan fitur, atau modifikasi kode pada proyek ini, **SELALU** sediakan dan perbarui berkas deploy:
1. Pastikan berkas konfigurasi deploy (`vercel.json`, `netlify.toml`, `VERCEL_DEPLOY.md`, `DEPLOY.md`) tetap mutakhir dan benar.
2. Pastikan file build distribusi (`dist/` atau zip `sr-studio-vercel-dist.zip`) dan panduan cara deploy ke Vercel / Netlify / Cloud Hosting selalu disertakan dengan jelas dan siap pakai bagi pengguna.
3. Selalu infokan lokasi file deploy / instruksi deploy di akhir pesan respons.
